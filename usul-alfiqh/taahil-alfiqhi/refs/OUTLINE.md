## 3. How the files relate

**الملف الشامل للتأهيل vs the five lecture summaries.**
- Same cover, same lecturer line, same layout and fonts. Fuzzy text matching plus a visual check of every page: shamil PDF 1–13 = taahil1 1–13; shamil 14–22 = taahil2 2–10; 23–29 = taahil3 2–8; 30–39 = taahil4 2–11; 40–47 = taahil5 2–9. The wording is identical (word-level diff shows only extraction noise).
- Differences in the shamil: (a) the covers of lectures 2–5 are dropped; (b) page numbers run continuously (1–68) instead of restarting; (c) the Telegram footer and «تم تلخيص المحاضرة» at the end of L1, L2, L4 and L5 are replaced by the «تذكير» box (one footer remains at the very end, PDF 69); (d) different yellow highlights (see 5).
- **The shamil has MORE content: lectures 6, 7 and 8 (PDF 48–69, 22 pages)** have no separate summary file in the folder. So the shamil is a strict superset: lectures 1–5 identical, plus lectures 6–8.
- Small textual variant: taahil4 PDF 3 reads «فلا قل لهما» (missing ت). Check the shamil PDF 32 wording when transcribing; use the correct verse «فَلَا تَقُلْ لَهُمَا».

**القواعد الفقهية vs التأهيل الفقهي.**
- A **separate series**: its own cover («تفريغ ملخّص لسلسلة: القواعد الفقهية»), with no «التأهيل الفقهي» or «على مذهب الإمام الشافعي» in its title; its own lecture numbering (lectures 1–6, restarting at 1, with no «المحاضرة الأولى» heading, like the usul file); a different subject (qawa'id fiqhiyya, not usul); its own closing «تم تلخيص السلسلة».
- **Zero text overlap** with shamil-taahil: no page of shamil 48–69 or 1–47 matches any qawaid page.
- Common to both: the same lecturer, transcriber and Telegram channel, and the same Shafi'i frame. The usul file's closing note (PDF 69) calls itself «سلسلة الدروس المتعلقة بأصول الفقه في حقيبة التأهيل الفقهي»: the «حقيبة» (package) apparently holds more than one series, so the qawaid series is probably the package's second component. As a text, though, it is a separate series and course.

**Important content note.** Despite its title, «التأهيل الفقهي على مذهب الإمام الشافعي» is **entirely Usul al-Fiqh**. It contains no furu' fiqh. It follows the Waraqat order and keeps citing al-'Imriti's nazm of the Waraqat, plus al-Suyuti's al-Kawkab al-Sati' and Jam' al-Jawami'. The site already has `usul-alfiqh/` with `sharh-alwaraqat`, `madkhal-usul-alfiqh` and `sharh-manzumat-usul-alfiqh`, so there is a real risk of thematic overlap with those courses. Decide the placement (`fiqh/` as the source folder suggests, or `usul-alfiqh/`) with that in mind.
